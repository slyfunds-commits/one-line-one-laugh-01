## The line

> My son's report says 'easily distracted'. It took 11 pages to say it.

69 characters, 69 bytes — one funny line of text, whole and self-contained.

The joke turns on the report itself: a two-word verdict that needed
eleven pages to arrive. The school's own paperwork is the evidence
against its own claim.

## How it works

`main.py` (pure Python standard library) writes the line byte-exact to
`/output/entry.txt`, with no trailing newline.
